EasyMarkdown Lite
=================

EasyMarkdown の Keep モードを利用する、サーバー不要のローカル Web 版です。

使用方法
--------
1. Microsoft Edge または Google Chrome で index.html を開きます。
2. 「フォルダーを開く」を選び、Markdown を保存しているフォルダーへの
   読み取り・書き込み権限を付与します。
3. 左側のファイルツリーから文書を選び、編集後に Ctrl+S で保存します。
4. 上部の「組版」から本文幅、文字サイズ、行間、フォントを調整できます。
5. 下部のステータスバーで現在のファイル、保存状態、表フィルターを確認できます。
6. 「ソース」は同じボタンで開閉でき、ソースをスクロールするとプレビューも追従します。

注意事項
--------
- 文書内容はサーバーへ送信されません。
- ブラウザーの企業ポリシーによって File System Access API が禁止されている場合、
  直接保存は利用できず、ダウンロード保存に切り替わります。
- リアルタイムのファイル監視、Explorer 連携、既定アプリ設定は提供しません。
- 相対パス画像と文書リンクを利用する場合は、単一ファイルではなく
  「フォルダーを開く」から文書を開いてください。
